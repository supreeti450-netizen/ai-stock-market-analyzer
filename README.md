# AI Stock Market Analyzer

A full-stack stock market analysis platform built using React, Node.js, Express and PostgreSQL.

## Features

- User Authentication (JWT)
- Portfolio Tracking
- AI Stock Recommendations
- Watchlist Management
- Price Alerts
- Interactive Stock Charts
- Portfolio Analytics
- AI Advisor Dashboard

## Tech Stack

### Frontend
- React
- Axios
- Recharts

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
